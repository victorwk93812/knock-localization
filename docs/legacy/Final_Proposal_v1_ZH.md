# 壓克力板敲擊定位系統 — 期末專題計畫書

**平台：** STM32L475VG（B-L475E-IOT01A Discovery kit）· 9 顆加速度計 · 4 片壓電片 · 筆電端 Python 繪圖

---

## 一、專題概述

本專題利用敲擊產生的震動，偵測**手指敲在 45 × 45 cm 壓克力板上的位置**，並以結果驅動筆電上的互動畫面。

專題分為兩個評估層級：

| | 基準一 — 區域分類 | 基準二 — 連續座標定位 |
|---|---|---|
| 問題 | 敲擊落在 3 × 3 九宮格的哪一格？ | 敲擊位置 (x, y) 是多少公分？ |
| 原理 | 最近感測器（震幅最大者） | 震幅物理模型、壓電片到達時間差、資料驅動迴歸 |
| 輸出 | 離散：9 個區域之一 → 預設人像動作 | 連續：板上一點 → 漣漪動畫、人像轉頭指向 |
| 運算位置 | STM32（即時） | 筆電（Python），最佳的簡單方法可移植回 STM32 |

**兩個基準共用同一套硬體、韌體擷取流程與同一份敲擊資料集**，因此結果可以直接比較。基準一是基準二必須超越的基準線（量化標準見第七節）。

## 二、板面佈局

板面 45 × 45 cm，每格 15 cm。座標單位為公分，原點在板子正中央。

```
  y
  ↑  ┌─────────────┬─────────────┬─────────────┐
     │     I0      │     I1      │     I2      │   I0 (−15, 15)  I1 (0, 15)   I2 (15, 15)
     │             │             │             │
     ├──────────P0─┼─────────────┼─P1──────────┤   P0..P3 位於 (±7.5, ±7.5)
     │     I7      │  STM32 + I8 │     I3      │   I7 (−15, 0)   I8 (0, 0)    I3 (15, 0)
     ├──────────P3─┼─────────────┼─P2──────────┤
     │     I6      │     I5      │     I4      │   I6 (−15,−15)  I5 (0,−15)   I4 (15,−15)
     │             │             │             │
     └─────────────┴─────────────┴─────────────┘ → x
```

- **I0–I7：** 外接 IMU，位於外圍 8 格的中心。
- **I8：** Discovery 板上內建的 LSM6DSL，位於中央格。它在 PCB 上的實際位置與板子中心有偏移，需實測。加入 I8 後多了**第 9 個區域（中央格）**，這是原本 8 區方案無法偵測的。
- **P0–P3：** 壓電片，位於內側四個格線交點，遠離板緣以減少反射。
- **區域編號 = 感測器編號**（0–8）。
- **九宮格標記：** 壓克力為透明材質，可列印紙本模板（格線加上第七節的 6 cm 測試網格）貼在板下。同一張模板也作為基準二資料集的標記敲擊點。
- **感測器方向：** 所有 IMU 以相同方向安裝（板上絲印 +x 箭頭朝同一方向），確保各軸方向一致。

### 3.2 接線

**IMU**
- STM32 3.3 V / GND → TCA9548A VCC / GND。
- STM32 Arduino 排針 **D14 (SDA) / D15 (SCL)**（I2C1）→ TCA9548A SDA / SCL。*請以使用手冊 UM2153 確認腳位。*
- TCA9548A 通道 *k*（SDk / SCk）→ IMU *k* 的 SDA / SCL（k = 0…7）。IMU 的 VCC / GND 接 3.3 V / GND 電源軌。
- 每個多工器通道只接一顆 IMU，因此每個通道只會看到該模組本身的上拉電阻，不需額外加上拉電阻。
- 內建的 I8 位於板上內部的 I2C2 匯流排，已接好線，與 I2C1 互相獨立。

**壓電片前端電路**（組在麵包板上；一組共用偏壓加上 4 個相同通道）

- **中點偏壓 VMID ≈ 1.65 V（共用）：** 3.3 V 經 100 kΩ 到 VMID，VMID 經 100 kΩ 到 GND，VMID 對 GND 並聯 10 µF ∥ 100 nF。
- **每個通道 j = 0…3：**
  - 壓電片端子 A → VMID；壓電片端子 B → 節點 Pj。
  - Pj 與 VMID 之間接 1 MΩ（洩放電荷並設定直流準位）。
  - Pj 經 10 kΩ 到節點 ADCj（限流）。
  - BAT43 從 ADCj 到 3.3 V（陰極接 3.3 V），另一顆 BAT43 從 GND 到 ADCj（陰極接 ADCj），將腳位箝制在安全範圍。
  - ADCj 對 GND 接 1 nF（抗混疊濾波，截止頻率約 16 kHz）。
  - ADCj → Arduino **A0–A3**。

用力敲擊時，壓電片可產生數十伏特的電壓；串聯電阻與箝位二極體可將 ADC 腳位維持在 0–3.3 V。由於訊號源阻抗為 10 kΩ，ADC 取樣時間須設定得夠長以確保穩定。

### 3.3 固定方式

原則：**感測器與板子剛性耦合；板子與桌面隔離。**

- **IMU：** 以薄層三秒膠將模組平貼於板面。避免使用泡棉膠帶，因為它會吸收我們要量測的震動。（若板子可打孔，也可用 M2.5 螺絲加薄墊圈固定，但不要用銅柱墊高。）
- **壓電片：** 黃銅面以薄層三秒膠直接黏在板上。使用附引線的壓電片，或在黏貼前先焊好引線。
- **Discovery 板（中央）：** 板上 IMU 即為感測器 I8，因此必須牢固固定。若板子可打孔，用 ≤ 5 mm 的短硬質墊片並鎖緊；否則以薄雙面膠加上邊緣熱熔膠固定。它的耦合程度會與膠黏的 IMU 不同，以各通道增益校正（測試 T7）處理。
- **線材：** 所有線材沿走線路徑以膠帶平貼，並在麵包板與 USB 接頭處做應力釋放。線材拍打板面會產生偽敲擊訊號。
- **腳墊：** EVA 腳墊貼在比四角略往內的位置。

## 四、韌體：共用擷取流程

### 4.1 感測器設定與匯流排頻寬預算

- 只開加速度計（關閉陀螺儀），量程 **±16 g**（敲擊會使 ±2 g 量程飽和），**ODR 416 Hz**，FIFO 設為連續模式。
- **為何是 416 Hz：** 8 顆外接 IMU 透過多工器共用一條 400 kHz 的 I2C 匯流排。在 416 Hz 下，8 顆 × 每秒 416 筆 × 7 bytes（含標籤的 FIFO 字組）≈ 23 kB/s ≈ 210 kbit/s，未計定址開銷時匯流排負載約 55 %。833 Hz 則會超出匯流排容量。**高頻資訊由壓電片提供。**
- **輪詢讀取：** 每 10 ms 依序對 k = 0…7 切換多工器通道 k、讀取 FIFO 數量，並連續讀出累積的樣本（每顆約 4 筆）。I8 經 I2C2 平行讀取。
- **時間戳記：** MCU 計時器為每次連續讀取打上時間戳記；個別樣本時間依 ODR 間隔重建（若晶片支援，也可用 FIFO 時間戳記）。
- **壓電片：** ADC 以**每通道約 100 kS/s** 掃描 4 個通道，存入循環 DMA 緩衝區（約 50 ms）。已知的通道間掃描時差由軟體修正。

### 4.2 敲擊事件偵測

- **觸發：** 任一壓電片偏離 VMID 超過閾值。若尚未完成壓電片前端電路，則改以任一 IMU 的 |a| − 1 g 超過閾值作為觸發。
- **擷取窗口：** IMU 取觸發前 5 ms 至觸發後 40 ms；壓電片取觸發前 1 ms 至觸發後 10 ms。
- **防彈跳／不反應期：** 約 300 ms，依實測的板子餘震衰減時間調整（測試 T11）。

### 4.3 每次敲擊的特徵

- **IMU i（0–8）：** 峰值動態加速度 A_i = max_t |a_i(t) − g_i|，其中 g_i 為觸發前樣本求得的重力基準。可另取各軸峰值（尤其是垂直板面的 z 軸）與窗口能量。每個 A_i 乘上校正後的增益 c_i（測試 T7）。
- **壓電片 j（0–3）：** 起始時間 t_j（首次超過 k·σ_noise，或以互相關求得）、峰值震幅與能量。

### 4.4 傳送至筆電

經 ST-LINK 虛擬序列埠（USART1），鮑率 **921 600**（請確認 ST-LINK 支援此速率；否則使用最高的穩定速率）：

- **即時模式：** 每次敲擊送出一行 `HIT:<zone>`（基準一結果，於 MCU 上計算），以及一行特徵 `FEAT:<n>,<A0..A8>,<t0..t3>,<P0..P3>`（筆電端基準二的輸入）。
- **收集模式：** 每次敲擊傾印完整原始窗口（IMU 與壓電片樣本），供離線分析與訓練。此模式不在意延遲。
- **選用：** 以板載 es-WiFi 模組透過 TCP Socket（如 8002 埠）傳送相同內容，用於無線展示。請使用手機熱點，因為校園 Wi-Fi 常會隔離連線裝置。

## 五、基準一 — 區域分類（最近感測器基準線）

### 5.1 方法（於 STM32 上執行）

- zone = argmax_i (c_i · A_i)，i = 0…8。
- **串擾防護：** 只有當最大值至少為次大值的 r 倍時才接受結果（r ≈ 1.2–1.5，依資料調整），否則回報「不確定」且不觸發動作。
- 原方案也以「最先驟升」作為判斷依據。但在 416 Hz 的 IMU 取樣率下，板上各點的到達時間差小於一個取樣週期，因此基準一**只用震幅**。時間資訊交由基準二的壓電片處理。

### 5.2 筆電端：人像動作

Python 腳本（`pyserial` + `pygame`）讀取 `HIT:<zone>`，驅動人像狀態機：**待機（呼吸循環）→ 動作 → 回到待機**。

| 區域 | 位置 | 動作 |
|---|---|---|
| 0 | 左上 | 揮手打招呼 |
| 1 | 中上 | 點頭同意 |
| 2 | 右上 | 鼓掌歡呼 |
| 3 | 右 | 向右側轉身 |
| 4 | 右下 | 抱頭驚訝 |
| 5 | 中下 | 開懷大笑 |
| 6 | 左下 | 鞠躬致謝 |
| 7 | 左 | 向左側轉身 |
| 8 | 中央（新增） | 跳躍 |

素材：9 組連續幀 Sprite（或 GIF、3D 動畫片段），加上一組待機循環動畫。

## 六、基準二 — 連續 (x, y) 座標定位

基準二由一系列方法組成，全部在同一份資料集上評估，每一步都應優於前一步。

**2a. 震幅加權質心**（最簡單的連續估計，可在 MCU 上執行）
(x, y) = Σ w_i r_i / Σ w_i，其中 w_i = (c_i A_i)^p，指數 p 依資料調整。不涉及任何物理模型。

**2b. 震幅物理模型**
A_i = S · ρ_i^(−1/2) · e^(−α ρ_i)，其中 ρ_i = √(|r − r_i|² + ρ₀²)。
此模型結合柱面波擴散與阻尼衰減；ρ₀ 用於正規化近場。未知數為 (x, y, S)；α 與 ρ₀ 以校正資料一次擬合。以對數空間的非線性最小平方法求解（`scipy.optimize.least_squares`）。未知的敲擊力道 S 在震幅比值中會自動消去。

**2c. 壓電片到達時間差（TDOA）**
t_j = t₀ + |r − p_j| / v_eff，未知數為 (x, y, t₀)，以最小平方法求解。彎曲波具**色散性**（c ∝ √f）。對 5 mm 壓克力的粗略估計為 100 Hz 時 c ~ 40 m/s、1 kHz 時約 130 m/s，因此壓電片訊號須先帶通濾波至固定頻帶，並以已知位置的敲擊校正 v_eff。

**2d. 資料驅動迴歸**
以對數震幅比 log(A_i / ΣA)、壓電片時間差與壓電片震幅等特徵，透過 k-NN 迴歸、高斯過程迴歸或小型 MLP（`scikit-learn`）映射到 (x, y)，以網格上的標記敲擊資料訓練。

**延伸目標：** 將 2b／2c 的估計值作為 2d 的額外特徵；將最佳的輕量模型（如 k-NN 或 2a）移植到 STM32。

### 6.1 物理討論（報告的核心分析）

在 IMU 頻寬內（≲ 200 Hz），5 mm 壓克力中的彎曲波波長約 0.3–0.4 m，與板子本身尺寸相當。因此響應主要由**板的振動模態**主導，而非向外傳播的行進波。我們預期在此區間簡單的衰減模型（2b）會有偏差，而資料驅動迴歸（2d）能學到隨位置變化的模態形狀「指紋」。壓電片可感測 kHz 頻段，此時波長約 10 cm，板子更接近傳播介質，有利於 TDOA（2c）。哪種方法在哪個頻段、板上哪些位置（板緣、腳墊附近）勝出，是本專題的主要分析成果。

### 6.2 筆電端視覺化

- 板面地圖：在估計的 (x, y) 處播放漣漪動畫、顯示不確定度圓，並在評估時即時呈現誤差熱圖。
- **人像轉頭並伸手指向敲擊位置。** 這是連續控制，銜接了基準一的離散動作與基準二的連續輸出。

## 七、評估方法

### 7.1 資料集
- **測試網格：** 7 × 7 點，x, y ∈ {−18, −12, −6, 0, 6, 12, 18} cm（共 49 點，印在板下的模板上）。
- **每點敲 15 次**，至少 2 人，以指尖或指節中等力道敲擊，共約 735 次，以收集模式記錄（原始資料）。
- **穩健性測試組：** 輕敲與重敲；筆與指節；板上放置物品；未參與訓練的人。
- 所有方法都在**完全相同的錄製資料上離線評估**，再將最佳方法即時執行。

### 7.2 資料切分
1. 依敲擊隨機切分（位置在訓練時出現過）。
2. **留點切分**（位置在訓練時從未出現），這才是連續定位的真正考驗。

### 7.3 指標
- **基準一：** 9 類準確率與混淆矩陣。誤差也以公分表示：將每個預測區域對應到該格中心，以便與基準二比較。
- **基準二：** 平均、中位數與第 90 百分位的歐氏距離誤差（cm）；板面誤差熱圖；以及衍生的區域準確率（將每個 (x, y) 對應到所在格子），以便與基準一直接比較。
- **系統：** 從敲擊到人像反應的端到端延遲，以手機慢動作錄影量測（240 fps，解析度約 4 ms）；每 10 分鐘的誤觸發次數，分別在靜置以及有人在同一張桌上打字時測量。

### 7.4 成功標準
- **基準一：** 敲擊格子中心附近時，區域準確率 ≥ 95 %。
- **基準一的量化下限：** 即使區域分類完全正確，回報格子中心的平均誤差仍約為 0.38 × 15 cm ≈ **5.7 cm**（正方形內均勻隨機點到中心的平均距離）。**基準二必須明顯優於此值才有意義。目標：中位數誤差 ≤ 3 cm。**
- **延遲：** 從敲擊到螢幕反應 ≤ 100 ms。

| T2 | **多工器：** 寫入 `1 << k` 至 0x70 並讀回；對每個通道做 I2C 掃描 | 通道 0–7 各恰好找到一顆 IMU |
| T3 | **匯流排完整性：** 8 顆 IMU 全接 30 cm 線、400 kHz；讀取 10⁶ 次（約 30 分鐘）；以邏輯分析儀檢查波形邊緣 | 0 錯誤（備案：降至 100 kHz 或加強上拉電阻） |
| T4 | **吞吐量與時序：** 量測輪詢迴圈時間（GPIO 翻轉 + 邏輯分析儀，或 DWT 週期計數器）；觀察 FIFO 水位 10 分鐘 | 416 Hz 下 FIFO 無溢位 |
| T5 | **設定與飽和：** 計算每顆 IMU 每秒的樣本數；在 IMU 旁邊用最大力道敲擊 | ODR 正確；峰值低於 ±16 g |
| T6 | **雜訊底線：** 每顆 IMU 靜置 60 秒；計算 RMS | 閾值設為 ≥ 5σ |
| T7 | **增益校正：** 對每顆 IMU，在其往板中心方向 5 cm 處敲 20 次 → 求得增益 c_i。對稱性檢查：敲擊中心時，4 顆邊 IMU 的震幅應相等，4 顆角 IMU 的震幅也應相等 | 校正後差異 < 10 % |
| T8 | **固定方式比較**（在壓克力邊角料上，正式組裝前）：三秒膠、薄雙面膠、熱熔膠 | 選擇震幅最高且重現性最好的方式 |
| T9 | **壓電片前端：** 以三用電表量測 VMID；檢查 ADC 靜置準位；記錄最大力道敲擊 | VMID = 1.65 ± 0.05 V；ADC 靜置於約中間值；箝位有效、無損壞 |
| T10 | **壓電片時序檢查：** 直接敲在壓電片上方，再敲板子中心 | 最近的壓電片最先觸發；敲中心時到達時間對稱；估計出 v_eff |
| T11 | **餘震衰減：** 記錄敲擊後的衰減尾巴 | 據以設定防彈跳時間 |
| T12 | **端到端延遲與誤觸發**（見 7.3） | ≤ 100 ms；每 10 分鐘誤觸發約 0 次 |
| T13 | **長時間運作與復原：** 連續運作 30 分鐘；拔插一條 IMU 線 | 不當機；I2C 匯流排復原程序（9 個 SCL 脈衝 + 重新初始化）可恢復運作 |
| T14 | **耗電：** 全部感測器接上時的 3.3 V 總電流（三用電表串聯量測） | 遠低於板上穩壓器的供電能力 |

## 十、風險與對策

| 風險 | 對策 |
|---|---|
| I2C 頻寬將 IMU 取樣率限制在約 416 Hz | 由壓電片提供高頻資訊；若 IMU 震幅資訊不足，改用 SPI（每顆 IMU 6 條線）或將 IMU 分到兩條 I2C 匯流排 |
| 在地買不到 LSM6DSOX | 改用其他單一型號（LSM6DS3TR-C／BMI160／ADXL345）；絕不混用型號；調整 FIFO 驅動程式 |
| 板的振動模態與邊緣效應使物理模型產生偏差 | 以資料驅動迴歸（2d）與校正處理；並在報告中說明頻段依賴性（6.1） |
| 中央主控板的耦合程度與膠黏 IMU 不同 | 各通道增益校正（T7） |
| 線材晃動造成偽敲擊 | 線材平貼固定、做應力釋放、使用串擾防護 |
| 校園 Wi-Fi 隔離連線裝置 | 預設使用 USB 虛擬序列埠；Wi-Fi 展示時使用手機熱點 |
